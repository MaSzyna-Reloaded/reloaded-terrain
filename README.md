# reloaded-terrain

Terrain3D (TokisanGames, v1.0.2-stable, `vendor/terrain3d`) patched for the worlds of MaSzyna
Reloaded and built double precision, with `WorldTerrainStreamer` - the terrain of a world streamed
around the camera. Released as `reloaded-terrain-<tag>.zip` (`addons/terrain_3d`, `addons/reloaded_terrain`),
which the game, the scenery importer, the world assets and the worlds unzip into their `addons/`.

- `make build` (Linux), `make build-windows` (MinGW), `make dist` - see the Makefile.
- Tags are the date and time, `YYMMDDHHMM`; a project names the tag it takes.
